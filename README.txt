1) github.com par new repository banao (Public).
2) Is zip ki saari files upload karo (Add file > Upload files).
3) Agar .github folder upload nahi hua: Add file > Create new file, naam me likho:
   .github/workflows/build.yml
   aur build-workflow.yml ka poora text paste karke Commit karo.
4) Actions tab > Build APK > Run workflow. 5-10 min baad Artifacts me tts-apk download karo.
